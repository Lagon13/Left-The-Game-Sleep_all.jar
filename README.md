# 🌙 Left_the_game_sleep

플레이어가 서버를 나갔을 때 현실감 있는 **수면 NPC**를 생성하고, **디스코드 계정 연동 및 실시간 말풍선 기능**을 제공하는 마인크래프트 유틸리티 플러그인입니다.

---

## ✨ 주요 기능 (Key Features)

* **오프라인 수면 NPC 생성**
    * 플레이어가 서버에서 퇴장(Quit)하면 그 자리에 해당 유저의 스킨을 한 NPC가 생성되어 바닥에 누워있는 상태가 됩니다. (Citizens 애니메이션 적용)
    * 플레이어가 다시 서버에 접속(Join)하면 생성되었던 NPC가 자동으로 깔끔하게 사라집니다.
* **편리한 디스코드 계정 연동 시스템**
    * 인게임에서 `/연동` 명령어를 통해 3분 동안 유효한 4자리 인증 번호를 발급받을 수 있습니다.
    * 채팅창에 뜬 인증 번호를 **마우스로 클릭하면 자동으로 클립보드에 `!인증 [코드]`가 복사**되어 편리함을 제공합니다.
    * 디스코드 채널에 명령어를 입력하면 봇이 즉시 메시지를 삭제하여 **사생활을 보호**하고, 유저에게 개인 메시지(DM)를 통해 성공 여부를 알려줍니다.
    * 중복 연동(1계정 1디스코드)을 철저하게 방지합니다.
* **디스코드 실시간 말풍선 (TextDisplay)**
    * 연동된 유저가 디스코드에 채팅을 치면, 마인크래프트 월드에 누워있는 본인의 NPC 머리 위에 5초 동안 말풍선(TextDisplay)이 나타나며 디스코드 채팅 내용을 인게임에서 확인할 수 있습니다.
* **무적 샌드백 모드**
    * 잠들어 있는 오프라인 유저의 NPC를 때리면 체력은 달지 않고 타격 모션과 소리만 재생되어 샌드백처럼 활용할 수 있습니다.

## 📦 의존성 및 요구 사항 (Requirements)

이 플러그인은 다음 플러그인 환경이 사전에 구축되어 있어야 정상적으로 작동합니다.
* **Minecraft Server:** Paper / Spigot (1.20 이상 권장)
* **Citizens** (NPC 생성, 스킨 및 수면 포즈 적용)
* **ProtocolLib**

---

## ⚙️ 설정 파일 (`config.yml`)

처음 서버를 구동하면 `plugins/Left_the_game_sleep/` 폴더 내에 `config.yml` 파일이 생성됩니다.
플러그인이 정상 작동하기 위해 디스코드 봇 토큰을 반드시 입력하고 서버를 재시작해 주세요.

```yaml
# 디스코드 봇 토큰을 여기에 입력하세요.
bot-token: "YOUR_DISCORD_BOT_TOKEN_HERE"
```

---

## 📜 마인크래프트 명령어 (Minecraft Commands)

* `/연동` : 디스코드 계정과 연동하기 위한 4자리 인증 번호를 발급받습니다. (클릭 시 디스코드용 명령어 자동 복사)

---

## 🤖 디스코드 명령어 (Discord Commands)

* `!인증 [코드]` : 마인크래프트에서 발급받은 4자리 번호를 입력하여 계정 연동을 완료합니다. (입력 즉시 채팅이 삭제되며 봇이 DM으로 결과를 안내합니다.)
